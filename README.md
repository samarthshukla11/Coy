# Coy – Matching App

A simple swipe-based matching application built as part of the Coy SDE Intern Assignment.

Users can discover profiles, like or pass on them, and see their matches when both users like each other.

## Features
- Browse profiles and swipe left or right.
- Like and pass using buttons or drag gestures.
- Get notified when a like is mutual.
- View your matches.
- Swipes and matches remain saved after refreshing.

## Tech Stack
- Frontend: React.js
- Backend: Node.js, Express
- Database: SQLite

## Run Locally

**Backend**
```bash
cd backend
npm install
npm run dev
```

**Frontend** (open another terminal)
```bash
cd frontend
npm install
npm run dev
```

The frontend runs at `http://localhost:5173` and the backend at `http://localhost:5000`.
